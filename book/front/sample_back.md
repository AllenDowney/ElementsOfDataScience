# About the Complete Book {.unnumbered}

This sample contains two chapters of *Elements of Data Science*. The
complete book has three parts and two case studies: an introduction to
Python for working with data, exploratory data analysis, and statistical
inference, followed by case studies on political alignment and on
algorithmic fairness in the criminal justice system.

For each chapter there is a Jupyter notebook you can run on Colab, with no
software to install, from <https://allendowney.github.io/ElementsOfDataScience>.
