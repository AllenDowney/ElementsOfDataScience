# Thank You {.unnumbered}

Thank you for reading *Elements of Data Science*.

For each chapter there is a Jupyter notebook you can run on Colab, with no
software to install, from <https://allendowney.github.io/ElementsOfDataScience>.
The notebooks have the code from the book and the exercises; working on the
exercises is the best way to learn the material.

If you found this book useful, please consider [supporting free, open
educational materials](https://greenteapress.com/support/?book=eds) from
Green Tea Press.
